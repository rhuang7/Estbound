# EASTBOUND V24 · 新增三篇及首页旅行者视角布局

## 更新
- 保留 V23 原有 3 篇马蜂窝游记，新增 3 篇；站内总计 6 篇。
- 新增 ID: `8390242`、`24386920`、`24525910`。全部原文图文顺序依据上传 PDF 截图，不做机器 OCR 文本重写。
- 已裁去网页侧栏与评论区域；每篇文章在详情页均有章节目录并支持点击放大。
- 首页“旅行者视角”初始只展示**完整一行**：桌面 3 篇，中屏 2 篇，手机 1 篇。

- 修改城市筛选或搜索后，展开状态重置为一行；窗口尺寸变化时也会保持行宽一致。

## 版权与数据限制
- PDF 为网页截图，没有可复制文本层；文章以内嵌长图保存原文图文顺序。
- 已删除可见评论和大部分页脚。网站载入的文本、图像和截图的转载许可仍未核实；公开发布前需取得权利人授权。
- 原网页中未正常加载的图像不能从 PDF 中恢复。

## 部署
请解压完整 ZIP 后，将其内容覆盖 GitHub Pages 发布目录。确保 `journal_media/` 下三个新增 ID 文件夹与 JS 数据文件一起上传。清理缓存后访问首页，以 `V24` 为准。
