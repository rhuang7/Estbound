# EASTBOUND V43 · 全站餐厅重建及实景图

版本：V43（2026-11-15）

## 内容

- 完整移除旧版 570 条餐厅候选的页面脚本引用与首页静态展示内容；**不再加载 `restaurants_v41.js`**。
- 为网站全部 19 个目的地建立新的 16 条记录/目的地，共 **304 条**，满足至少 15 家/目的地（自然景点包含附近明确标注的城镇）。注意：新名单基于旅游局名录、旅游指南等资料线索，**不意味着逐家核实2026年的经营状态**。
- 通过照片源页面名称匹配了 40 张实际店铺/室内照片，覆盖 19 个目的地。其他卡片采用明确标记的「实景照片待核实」照片区，并提供 Google Maps 查看相应店铺照片的链接，绝不以其他商家/城市照片假充。
- 首页和地点详情均采用相同图片匹配数据；原有目的地筛选、加载更多、详情地图及购物栏目不动。
- 正式商业发布前需取得图片使用许可。在线图片由第三方服务器提供，可能因热链限制加载失败；失败时页面会提示访问照片来源。

## 安装

把更新包内的 `home.html`, `place.html`, `reading.js`, `place.js`, `restaurants_v43.js`, `restaurant_photos_v43.js`, `restaurant_photos_v43.css`, `EASTBOUND_V43_DINING_MANIFEST.csv` 复制到网站根目录并覆盖前4个同名文件；其他为新建文件。

`index.html` 仍按原版跳转播放器 `player.html` 和首页，无需改动。之前的 `restaurants_v41.js` 仍可留在文件夹但不会再被加载；可自行删除。

## 图片/数据审校

详见 `EASTBOUND_V43_DINING_MANIFEST.csv`，逐条列出餐厅名称、地区、资料来源、照片网址及照片出处。

注意：餐厅数据是**餐饮检索线索**，不是最新开业、可预订或用户评分承诺；景区周边扩展不代表位于景区内。
