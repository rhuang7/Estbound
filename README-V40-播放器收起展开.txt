EASTBOUND V40 · BGM 悬浮控件可收起 / 展开

适用版本：已安装 V39 双曲目 BGM 的网站。

升级方法：将 ZIP 里的三个文件上传至 GitHub Pages 仓库发布根目录，覆盖已有的同名文件：
1. player.html
2. bgm-player.js
3. bgm-player.css

无需重新上传音乐、assets 文件夹或 17 篇游记。

新功能：
- 展开时保留上一首、播放/暂停、下一首及曲目标题。
- 点击右边的箭头可收起为一颗悬浮圆形音乐按钮，再点击即可展开。
- 收起动作不会暂停、重置或切换音轨。仍可跨页面持续播放。
- 浏览器允许本地存储时，会记住用户上次的收起/展开选择。
- 小圆点（亮绿色）表示播放器当前正在播放。
- 电脑版和手机版均有对应布局。

说明：首次有声自动播放仍受浏览器策略限制。音乐公开使用需确认授权。
