EASTBOUND V27 / 安装说明

完整包：EASTBOUND_V27_FULL_SITE.zip 解压后上传全部文件到 GitHub Pages 发布目录。

如果完整包下载失败：分别下载 EASTBOUND_V27_SITE_PART_01.zip 到最后一份；将每个 ZIP 单独解压到【同一个空文件夹】，允许合并各层文件夹。请不要直接拼接 ZIP 二进制文件。合并后的目录就是完整网站。

如果已经部署 V26：也可用 EASTBOUND_V27_UPGRADE_FROM_V26.zip，只需覆盖其中的同名文件并保留原有网站资源。若补丁单包下载失败，下载 UPGRADE_PART_01 及以后各小包，分别解压到同一个文件夹后上传覆盖。
