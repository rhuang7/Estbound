# EASTBOUND V31 · 三篇新游记 + 全站不中断 BGM

- 原有10篇保留，本次新增3篇独立马蜂窝游记，合计13篇。
- 来自 PDF 截图的图文内容按原帖顺序连续展示，不进行 OCR 识别，避免文本错误；原文及图片转载权限仍待核实。
- `index.html` 是启动入口，会进入 `player.html` 的全站持续音乐外壳。`home.html` 是原首页。
- 所有站内页面通过播放器外壳中的浏览框打开，跨页面切换时音频元素**不重新加载**，右侧始终可控制播放/暂停。
- 直接打开 `journal.html?id=...` / `travelogues.html` 等旧地址会自动进入同一音乐外壳并保持对应页面，避免深度链接失效。
- 浏览器通常禁止未经操作的有声自动播放：初次访问会尝试自动播放，未获许可时点右侧按钮或点击页面后开启。
- 音乐默认音量55%，循环；手动暂停后不会被其他点击自动重新启动。
- 网站为静态 GitHub Pages，无需服务器端组件。主页索引和其它页面应一起部署。
- 若你曾部署旧版，建议在发布后强制刷新一次。
