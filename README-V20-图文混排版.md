# EASTBOUND V20 · 19 篇游记图文混排版

这是从 V19 完整网站升级的 GitHub Pages 静态网站。**请部署整个压缩包内的文件及目录**，不要只上传 `journal.html`。

## 本次变化

- 19 篇导入游记继续保留在首页、游记列表和详情页，旧游记没有恢复。
- 为每一张原帖照片记录对应的文章段落位置 `afterParagraph`（从 **0** 开始，以 `licensed_journals_data.js` 中原始 `paragraphs` 数组为准）。位置来自原始网页结构和景点、城市、活动主题的针对性校准。
- 详情页 `journal.html` / `report_reader.js` 现在先排原文，再在相应段落之间插入照片，不再另设统一的文末相册。
- 较长段落只调整显示换段，不删改原文字句；章节标题、分项信息、旅行基本资料得到更清晰的排版。
- 桌面双图网格、手机单图排列、等比例图片、点击查看原图和图片来源链接均可用。
- 原始图片资源 **100 张文件都保留**；其中 4 张在单篇英文游记中与相邻图片字节完全重复，在页面中不再次显示，共实际显示 96 张。
- 有两篇原始数据没有图片，只改善文字段落排版；没有编造配图。
- 原始上传的《多伦多2日游纪行》仅采集到网站导航、游记元信息、封面，**没有有效正文**。V20 不再把网页导航误显示为游记正文，而是展示提示、原帖图片和原站链接。

## 调整图片插入位置

打开 `licensed_journals_data.js`，找到目标游记 `id` 的 `images` 数组。每张图片的 `afterParagraph` 表示它应该出现在正文哪个段落之后（下标从 0 开始）。

如果有很多图片关联同一个长段落，页面会自动在这个段落的句子分块之间分配图片；来源相近的照片会成组展示。

参见 `V20-图片与正文位置对照表.csv` 和 `JOURNAL-IMAGE-PLACEMENTS-V20.json`。

## GitHub Pages 发布

将 ZIP **内部全部文件与文件夹**（包括 `journal_media/`、全部 JS、CSS、HTML 文件）上传到 GitHub Pages 当前发布根目录，覆盖旧版同名文件。若浏览器仍显示旧网页，可强制刷新缓存。
