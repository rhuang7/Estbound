# EASTBOUND V45 — 82 张购物卡片图片补充

## 做了什么

- 基于 V44 已有的 17 个图片映射，新增剩余 65 个购物地点的图片地址，总计 82/82 个有对应的图片映射。
- 购物卡片继续使用固定尺寸封面（含加载失败时的替代设计），城市筛选、详情、地图和餐厅栏目保持原样。
- 街区照片标注“街区实景照片”；泛指商店类别的卡片可使用同一区域代表商铺的店面/店内照片，并以“地区/商户实景”标识，不暗示它是特定店铺。部分景区项目采用游客中心或入口照片，明确注明不是礼品店内部。
- 每张新增图片的卡片显示“拍摄地点”及“图片来源”链接。
- 部分照片来自商业摄影、第三方旅游网站、商圈网站、官方旅游局或 Wikimedia Commons，不保证已获得再使用许可。

## 重要局限

**全部 82 张卡片均已配置图片 URL，不等于全部 82 张图片已完成浏览器加载验证。** 图片外链可能失效、被防盗链屏蔽或将来变更；失败时显示原有占位封面而不是错误的商场照片。

另外，`Moncton Downtown Bookshops` 采用 Read’s Books & Coffee 所在建筑的实景（画面重点为其书店主题外墙艺术作品，并非书架内景）。`Marché du Vieux-Port 周边` 使用旧港附近 Rue Saint-Paul 现存商铺实景，**不使用已迁址旧市场的建筑照片**。`Vieux-Tremblant Shops` 等少数条目仍需进一步确认拍摄街段。

公开部署之前，请逐张检查图片是否仍可加载，核实图片使用许可（署名和来源链接本身不等于授权），如需要请改为权利人许可的本地图片。

## 安装

在已安装 V44 的网站根目录解压覆盖：
`home.html`、`shopping_photos.js`、`shopping_photos.css`、`explorer.js`。

清除缓存或强制刷新。该增量包不包含原网站的音频和游记媒体。
