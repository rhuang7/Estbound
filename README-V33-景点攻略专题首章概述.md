# EASTBOUND V33 — 加拿大海洋三省景点专题 · 第一章「概述」

基础版本：V32（17 篇游记），所有原有游记、音乐、餐厅、路线功能保留。

## 新增内容
- `maritimes-attractions-guide.html`：独立专题阅读页，专题标题使用用户提供的原文标题；目前只包含第一章「概述」。
- `maritimes-guide.css`：专题页排版及首页、游记库两处入口样式。
- `assets/guides/maritimes-scenic/`：从用户上传的图1精确裁出 3 张原文照片（含原始水印），含轻量 WebP 和 PNG 原图，另保留未修改的原始整页截图。
- `home.html`、`travelogues.html`：新增专题入口，放在现有游记列表之前，不影响原有 17 篇游记数量或展开按钮。

## 阅读与导航
- 用户访问 `index.html` 的跨页 BGM 播放器仍为父级。专题也会在独立打开时加入同一个播放器。
- 章节目录目前只有 `01 概述`，尚未提供后续内容，不会编造新章节。
- 文字是用户提供图1原文的手动转录，三张照片按图1顺序排列；点击可查看原始裁图。

## 部署
如已使用 V32，只需解压 `EASTBOUND_V33_UPGRADE_FROM_V32.zip` 并将其中所有文件/目录覆盖到 GitHub Pages 发布根目录。无须删除旧游记文件。
